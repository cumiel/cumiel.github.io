몽글 개인정보처리방침

시행일: 2026년 8월 12일 · Cumiel

몽글(이하 "앱")은 Cumiel(이하 "회사")이 운영하는 항공 좌석 추천·항공편 추적 앱입니다. 이 문서는 앱이 무엇을, 왜 수집하고, 이용자가 이를 어떻게 통제할 수 있는지 설명합니다. 회사는 서비스 운영에 필요한 최소한만 수집하며, 개인정보를 판매하지 않습니다.

1. 수집하는 정보

항목 수집 시점 목적
계정 정보 — 이메일, 이름(선택), 계정 식별자(UID) Google·Apple 로그인 시 추적 항공편·이용권을 기기 간에 유지
익명 식별자 — 무작위 ID 로그인 전 최초 실행 시 계정 없이 둘러보기 (개인정보와 연결되지 않음)
추적 데이터 — 등록한 편명·날짜 항공편 추적 등록 시 해당 편 실시간 상태 조회·알림 발송
푸시 토큰 — 기기 알림 토큰(FCM) 알림 허용 시 지연·게이트 변경·탑승 알림
설정 — 언어·통화·홈 위젯 구성 설정 변경 시 기기 간 설정 유지
구매 기록 — 구매 상품, 스토어 영수증(RevenueCat 처리) 이용권 구매 시 구매 검증·이용권 적립. 카드 정보는 회사가 접근할 수 없으며 결제는 Apple·Google 이 처리합니다.
좌석 리뷰 — 작성한 별점·내용 리뷰 작성 시 다른 이용자에게 표시 (가명 처리되어 노출)
광고 식별자 — 기기 광고 ID 무료 이용 시 (Google AdMob) 광고 표시. 이용권 구매 시 광고가 완전히 제거됩니다.

위치, 연락처, 사진, 건강 정보는 수집하지 않습니다. 게이트·수하물 벨트·항공기 위치 같은 운항 정보는 공항·항공 공공 데이터에서 오는 것으로 개인정보가 아닙니다.

2. 실시간 상황 공유

공유 링크를 만들면 해당 항공편의 편명·시각·게이트·벨트·상태가 공개 페이지에 표시됩니다. 계정 정보는 포함되지 않습니다. 링크를 아는 사람은 누구나 볼 수 있으며, 공유를 끄거나 추적을 종료하면 페이지가 즉시 삭제되어 링크가 무효화됩니다.

3. 제3자 서비스

서비스역할개인정보처리방침
Firebase (Google) 로그인·데이터베이스·푸시 알림·호스팅 Google
RevenueCat 구매 검증 (계정 ID·스토어 영수증 전달) RevenueCat
Google AdMob 무료 이용자 광고 Google Ads

운항 데이터 제공처(공공데이터포털, adsb.lol, AeroDataBox)에는 조회할 편명만 전달되며, 이용자가 누구인지는 전달되지 않습니다.

4. 보관 기간

  • 추적 항공편 — 운항 종료 후 비활성화되며, 앱에서 언제든 삭제할 수 있습니다.
  • 공유 페이지 — 공유 해제 또는 추적 종료 즉시 삭제됩니다.
  • 계정 데이터 — 계정이 존재하는 동안 보관하며, 계정 삭제 시 함께 삭제됩니다.
  • 구매 기록 — 환불 처리 및 법령상 의무 이행에 필요한 기간 동안 보관합니다.
